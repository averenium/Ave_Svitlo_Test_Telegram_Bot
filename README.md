# AVE.SvitloTest_TelegramBot

Ботом можна скористатись за посиланнням: https://t.me/ave_svitlo_test_bot (@ave_svitlo_test_bot)   

**Підтримується тільки Дніпро**


## Опис
**[НЕ ОФІЦІЙНИЙ]** Телеграм бот, що за групою відключень надає графіки відключень у **Дніпрі** (із Yasno для ДТЕК та ЦЕК) та повідомляє про зміни цих графіків.  
Крім того шукає інформацію в популярних групах про відключення світла і пересилає повідомлення якщо вповідомлені є обраний провайдер та група користувача.

## Архітектура проекту
*Назараз це робочий **ПРОТОТИП** написаний на 90% через AI і потребує доробок щоб вийти за межі прототипу. Є багато не вирішених проблем, але загалом задачу свою виконує.*

### AVE.ElectricityBot
Головний проект ASP.NET Core Web API з Telegram ботом та фоновим сервісом.

### AVE.ElectricityBot.YasnoApi
Бібліотека для роботи з API Yasno для отримання інформації про графіки відключень електроенергії.

### AVE.ElectricityBot.TelegramScraper
Скрапер повідомлень із Telegram preview public channel

## Функціональність

- ✅ Автоматична відправка повідомлень при оновленнях чи зміні графіку
- ✅ Відображення відключень на сьогодні та завтра
- ✅ Пересилка повідомлень про обрану групу із публічних каналів 


#### 🔍 Інтервал перевірки:

- Перевірка графіків із джерела кожні **5 хвилин**
- Повідомлення користувачам по змінам - кожну **хвилину**
- Перевірка повідомленнь в групах і пересилка всім підписаним - кожні **5 хвилин**
